Centauri Carbon Bed Mesh Visualizer

Load a saved bed mesh:

  1. Run Automatic Leveling on the printer.
  2. Export the printer diagnostic log to a USB drive.
  3. Extract the ZIP archive using password 16881688 (community reference; originally shared in the ELEGOO Official Discord).
  4. Open the extracted log folder and locate opt/usr/cfg/autosave.cfg.
  5. Upload or drag autosave.cfg onto this page.

The archive password is community-reported and may change in future firmware versions.

The file is processed locally in your browser and is not uploaded anywhere. Legacy Centauri Carbon printer.cfg mesh profiles are still supported.
